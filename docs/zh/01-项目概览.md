# 01 项目概览

## 项目定位

**freebuff2api** 是一个零运行时依赖的 OpenAI 兼容反向代理，目标：

1. 复用免费账号的 auth token，把标准 OpenAI API 请求转发到
   Freebuff（[freebuff.com](https://freebuff.com)，免费 AI 编码助手）的上游后端
2. 在本地暴露 OpenAI 兼容的 `/v1` 接口，让任何 OpenAI 客户端
   （Claude Code、Cline、LobeChat、curl…）都能驱动 Freebuff 的免费模型

技术栈：TypeScript + [Bun](https://bun.sh)（也兼容 Node 22+），无第三方依赖。

## 一句话原理

Freebuff 的免费档按 **会话（session）** 发放：每个账号同一时间只有一个
活动会话。代理对每次 chat 请求：

1. **获取免费会话** — `POST /api/v1/freebuff/session`
   （繁忙时进入"等待室"，代理向客户端返回 503 + Retry-After 并持续轮询）
2. **启动 Agent 运行** — `POST /api/v1/agent-runs`（`action: START`）
   按请求的 model 选择对应 Agent；run 可复用、按间隔轮换、关闭时自动结束
3. **优先公共链路** — 对白名单中的 OpenCode 模型，把原始 OpenAI body 发往固定 HTTPS 公共上游，不转发下游凭证。该链路默认开启，可用 `PUBLIC_UPSTREAM_ENABLED=false` 关闭。
4. **转发认证请求** — `POST /api/v1/chat/completions`，在 OpenAI 载荷中注入
   `codebuff_metadata`（`run_id`、`client_id`、`cost_mode: "free"`、
   `freebuff_instance_id` 等）以及 **CLI 身份 system 标记**
   （见 [04-请求格式破解](04-请求格式破解.md)）
5. **令牌轮换** — 配置多个 `AUTH_TOKENS` 时轮询使用；被上游 401 的令牌
   冷却 30 分钟，避免污染所有请求

## 目录结构

```
src/
  index.ts      入口：参数解析、启动服务器、优雅退出
  config.ts     配置加载（环境变量 > config.json > 登录凭证 > 默认值）
  login.ts      device-code 登录流程（生成链接、轮询状态、保存凭证）
  upstream.ts   Freebuff 认证上游 HTTP 客户端（会话/运行/chat 各端点 + 调试日志）
  public-upstream.ts  固定主机的 OpenCode 公共上游客户端与回退规则
  session.ts    会话池管理（SessionPool / TokenManager / 令牌冷却）
  runs.ts       运行管理（run 的启动、复用、轮换、关闭）
  models.ts     模型注册表（同步官方 Agent→模型映射）
  server.ts     node:http 适配器，承载共享请求处理器
  handler.ts    共享 Request→Response 路由、鉴权、校验与 CLI 标记注入
docs/           中文文档（本目录）
tools/          调试与分析辅助脚本（见 tools/README.md）
```

## 模块职责速览

| 模块 | 职责 |
| ---- | ---- |
| `login.ts` | `freebuff2api login` 命令；凭证存 `~/.config/freebuff2api/credentials.json` |
| `config.ts` | 解析 env / config.json / 登录凭证，统一输出 `Config` |
| `upstream.ts` | Freebuff 认证上游的会话/运行/chat 调用；`DEBUG_UPSTREAM=1` 可打印明文请求 |
| `public-upstream.ts` | 固定主机的 OpenCode 公共上游、模型白名单、凭证隔离、超时与回退分类 |
| `session.ts` | 每个令牌一个 `SessionPool`；`TokenManager` 负责轮换与冷却 |
| `runs.ts` | `RunManager` 按（token, agent）缓存 runId，到期轮换 |
| `models.ts` | 从 GitHub 拉取官方 `free-agents.ts` 解析 Agent→模型映射（6h 刷新） |
| `handler.ts` | 共享 `/healthz`、`/v1/models`、`/v1/chat/completions` 路由、公共上游优先、鉴权、校验、回退与 CLI 标记注入 |
| `server.ts` | 把 node:http 流适配到共享的 Web 原生处理器 |

## 对外接口

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET | `/healthz` | 存活检查 + 模型注册表 + 令牌会话状态 |
| GET | `/v1/models` | 当前免费可用的模型列表 |
| POST | `/v1/chat/completions` | OpenAI 兼容 chat（支持流式） |

## 设计要点

- **零依赖**：只用 Node/Bun 内置能力，`fetch` 原生支持 `HTTP_PROXY` 环境变量
- **会话共享**：同一令牌的并发请求共享一次会话刷新，避免打爆上游
- **优雅关闭**：SIGINT/SIGTERM 时先关服务器、再 FINISH 所有 run、
  最后 END 会话
- **容错**：session/run 无效时自动重试一次（刷新会话 / 轮换 run）；
  401 令牌进入冷却
