# 09 — 模型目录与路由

> 统一模型目录：`provider/model` 前缀规范 ID、去重后的裸别名、按供应商优先级
> 路由，以及图片生成。实现见 `src/models.ts`、`src/public-upstream.ts`、
> `src/handler.ts`。

## 规范 ID 与裸别名

每个模型同时以两种写法暴露：

| 写法 | 示例 | 用途 |
| ---- | ---- | ---- |
| 规范 ID | `pollinations/openai`、`freebuff/deepseek-v4-flash` | 带供应商命名空间，无歧义，精确选择推荐用这种 |
| 裸别名 | `openai`、`deepseek-v4-flash` | 快捷写法；跨全部供应商全局去重 |

`GET /v1/models` 会列出每个模型的规范 ID 与裸别名（去重、排序，OpenAI
`list` 形状，`owned_by: "freebuff2api"`）。带前缀的 ID 总是路由到对应供应商；
当裸别名可能属于多个供应商时，按 `PUBLIC_UPSTREAM_PROVIDERS` 的优先级顺序
路由（默认 `opencode, pollinations, felo`，公共优先），最后才回退 Freebuff。
因此别名只是便利写法，永远不会改变带前缀请求的去向。

## Chat 模型（`POST /v1/chat/completions`）

### Freebuff（需认证）

Freebuff 注册表全部模型（如 `deepseek/deepseek-v4-flash`）以
`freebuff/<model>` 加裸别名列出。它们需要 Freebuff token（`AUTH_TOKENS` 或
已保存的登录凭证），并且是兜底链路。

### OpenCode Zen（免认证）— 4 个

`big-pickle`、`deepseek-v4-flash-free`、`mimo-v2.5-free`、`nemotron-3-ultra-free`

OpenCode 沿用历史裸 ID（`opencode/<model>` 与裸 ID 是同一个字符串）。实测
`hy3-free`、`north-mini-code-free` 匿名调用返回 401，已从白名单移除。

### Pollinations（免认证）— 8 个

`openai`、`openai-fast`、`openai-large`、`qwen-coder`、`mistral`、
`deepseek`、`grok`、`perplexity-fast`

规范 ID 为 `pollinations/<model>`（如 `pollinations/openai`），裸别名
`openai`。`gemini-flash-lite-3.1`、`perplexity-reasoning` 匿名调用返回 401，
已移除。另外 Pollinations 匿名 chat 层对部分提示词形态也会返回 401（供应商侧
的抽签路由，不是代理的问题）；E2E 探针使用良性提示词并对瞬态失败重试。

### Felo（免认证，逆向网页协议）— 5 个

`felo-chat`、`felo-search`、`felo-scholar`、`felo-social`、`felo-document`

规范 ID 为 `felo/<model>`，裸别名 `felo-<model>`。Felo 没有官方 API，网页
协议可能随时变化。

## 图片模型（`POST /v1/images/generations`）

Pollinations 免认证图片端点（`https://image.pollinations.ai`）：
`flux`、`turbo`、`zimage`（规范 `pollinations/flux` 等，裸 `flux` 等）。

请求（OpenAI images API 形状）：

```json
{
  "model": "pollinations/flux",
  "prompt": "a tiny red circle on a white background",
  "size": "256x256",
  "n": 1,
  "seed": 42,
  "response_format": "b64_json"
}
```

| 参数 | 含义 |
| ---- | ---- |
| `model` | 白名单内的任意 `pollinations/*` 图片模型（带前缀或裸别名均可） |
| `prompt` | 必填的文本提示词 |
| `size` | `"WxH"` 像素尺寸，转发为 `width`/`height` |
| `n` | 生成数量；每张 seed 递增（seed + i） |
| `seed` | 可选；省略即随机 |
| `response_format` | `b64_json` → 每项只返回 `b64_json`；否则返回 `url`（`data:` URI）与 `b64_json` |

响应：

```json
{ "created": 1786000000, "data": [{ "url": "data:image/jpeg;base64,...", "b64_json": "..." }] }
```

说明：上游调用是无凭证的
`GET image.pollinations.ai/prompt/<prompt>?width=…&height=…&seed=…&model=…&format=jpeg`。
`nologo`（去水印）需要账号 token，代理**不会**发送——匿名结果始终带
Pollinations 水印。图片在响应前同步抓取并 base64 编码，延迟随生成耗时增长。

## 路由与回退

- **公共 chat**：公共路由开启且请求模型（前缀或裸别名）命中公共供应商时，
  优先走公共链路。瞬态失败（`401/408/425/429/5xx` 或超时）会继续尝试其他
  匹配的公共供应商，最后回退认证 Freebuff 链路（有 token 时）；不可重试的
  4xx 直接返回。
- **公共图片**：仅 Pollinations；瞬态失败直接透出（由客户端重试），不会在
  供应商之间重放。
- **Freebuff 模型**：`freebuff/<model>` 或裸别名在调用 session/run/chat 前
  统一规范化为真实模型 ID，确保上游始终收到正确的模型名。

## 配置开关

| 环境变量 | 默认值 | 作用 |
| ---- | ---- | ---- |
| `PUBLIC_UPSTREAM_ENABLED` | `true` | 关闭全部公共供应商 |
| `PUBLIC_UPSTREAM_PROVIDERS` | `opencode,pollinations,felo` | 启用的供应商 ID 与别名优先级顺序 |
| `PUBLIC_UPSTREAM_MODELS` | 聚合白名单 | 公共 chat 模型白名单（`provider/model` ID） |
| `PUBLIC_UPSTREAM_IMAGE_MODELS` | `pollinations/flux,pollinations/turbo,pollinations/zimage` | 图片模型白名单 |
| `PUBLIC_UPSTREAM_TIMEOUT` | `20s` | 首响应超时后回退 |

完整配置参考：[07-配置与使用](07-配置与使用.md)。
