# 06 端到端测试记录

> 本文记录整个开发与逆向过程中的关键测试与结论，供复现与排查参考。
> 测试均使用真实账号（登录凭证位于
> `~/.config/freebuff2api/credentials.json`）。

## 阶段 1：登录流程验证 ✅

| 测试 | 结果 |
| ---- | ---- |
| `bun run login` 生成链接 | ✅ 输出 `freebuff.com/login?auth_code=…` |
| 浏览器完成登录 | ✅ 打印 `Login successful! Return to your terminal to continue.` |
| 轮询拿到 user 记录 | ✅ `name/email/authToken` 完整 |
| 凭证落盘 | ✅ `credentials.json`（`default` 键） |
| 服务器自动使用凭证 | ✅ `/healthz` 中 `acting_user_id` 为登录用户 id |

踩坑记录：

- 同一账号同时只有 1 个活动会话。官方 CLI 若占用会话，会报
  `Another instance of freebuff has taken over this session`，
  需用另一账号重新登录。

## 阶段 2：会话 / 运行端点 ✅

| 请求 | 结果 |
| ---- | ---- |
| `POST /api/v1/freebuff/session`（body `{}` 或无 body 均可） | ✅ 200 `status: active` + `instanceId` |
| `GET /api/v1/freebuff/session`（带 instance-id） | ✅ 200 |
| `POST /api/v1/agent-runs` START（`base2-free-deepseek-flash`） | ✅ 200 `runId` |
| `POST /api/v1/agent-runs` FINISH | ✅ 200 `{success:true}` |
| `DELETE /api/v1/freebuff/session` | ✅ 200 `{status:"ended"}` |

## 阶段 3：chat 端点的 403 之谜（关键）

最初所有 chat 请求都返回 `403 free_mode_cli_required`，即使
session/run 都成功。经过：

1. MITM 抓取官方 CLI 成功请求（见 `tools/mitm-ssl-proxy.mjs`）
2. 变体二分（见 `tools/discover-gate.mjs`）

确定网关检查的是 **system 消息中的精确短语**
`You are Buffy, the strategic coding assistant`。

详见 [04-请求格式破解](04-请求格式破解.md) 的完整测试表。

## 阶段 4：修复后全链路验证 ✅

启动代理并请求：

```bash
DEBUG_UPSTREAM=1 LISTEN_ADDR=:18080 bun run src/index.ts
```

### 流式 chat

```bash
curl -sN http://127.0.0.1:18080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4-flash","stream":true,"messages":[{"role":"user","content":"Reply with exactly: PONG"}]}'
```

结果：✅ HTTP 200，SSE 推送：

```
: connected 2026-08-06T18:21:16.504Z
data: {"id":"93390497-…","object":"chat.completion.chunk","model":"deepseek/deepseek-v4-flash",…}
```

### 非流式 chat

```bash
curl -s http://127.0.0.1:18080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4-flash","messages":[{"role":"user","content":"Reply with exactly: PONG"}]}'
```

结果：✅ HTTP 200，真实回复：

```json
{ "choices": [ { "message": { "role": "assistant", "content": "PONG",
  "reasoning_content": "The user wants me to reply with exactly \"PONG\"…" } } ],
  "usage": { "prompt_tokens": 459, "completion_tokens": 19, "total_tokens": 478,
             "cost": 0, … } }
```
